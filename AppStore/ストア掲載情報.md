## Appのプライバシー（「栄養ラベル」）

「データの収集」の質問に **「いいえ、このAppからデータを収集しません」** と答えて公開します。

理由：広告もない、分析ツールも入れていない。進みぐあい（どのステージまで進んだか・音とかたむきのオン/オフ）は iPhone の中（UserDefaults）にだけ保存されます。Game Center に送るスコアは Apple が管理するもので、開発者は受け取りません。1.4 で入れた「1日1回のバージョン確認」は、アプリのIDと国を App Store に聞くだけで、利用者のデータは送りません。かたむき（モーションセンサー）の値も端末の外には出ないので、答えは変わりません（答える前に App Store Connect のヘルプ「App のプライバシーに関する詳細」で最新の扱いを確認してください）。

## 年齢制限

質問はすべて「なし」「いいえ」で答えます（暴力・ギャンブル・ユーザー同士のやりとり・Webブラウズ・広告・App内課金、いずれもなし）。結果は一番低い区分（4+）になるはずです。

## 輸出コンプライアンス（暗号化）

Info.plist に「暗号化を使っていない（ITSAppUsesNonExemptEncryption = NO）」と書いてあるので、ビルドごとに聞かれることはありません。

## 審査メモ（App Reviewへのメッセージ欄に英語で貼る）

「App Review に関する情報」→「メモ」に貼っておくと、審査の人に「中身がきちんとしたゲームであること」が伝わりやすくなります。ログインは不要なので、サインイン情報の欄はオフにします。

```
Mochitto Tsumitsumi (Mochi Stack) is a physics puzzle game that runs fully offline (the network is only used for Game Center and a daily update check). No account, no ads, no in-app purchases. If the player is signed in to Game Center, scores are submitted to Game Center leaderboards. The app is available in Japanese and English (it follows the device language).

How to play: tap the screen to drop a rice cake (mochi). Stack them so the top stays above the gold line for 2 seconds to clear the stage. Each stage gives a fixed set of mochi. The five mochi types have different physics (weight, softness, stickiness, friction), so the stacking order matters: for example, heavy "anko" is a stable base, and powdered "kinako" makes anything on top slide off.

The game engine is bundled inside the app and runs locally. It uses native iOS features: haptic feedback on landing, clear and fail; progress saved on the device with UserDefaults; Game Center leaderboards (Records > World Ranking); an ambient audio session so it respects the silent switch and the user's music.

"Free Play" mode (on the home screen) lets you drag and stretch the mochi without goals.

Tilting the iPhone tilts gravity slightly so the player can balance the stack (CoreMotion; toggle with the phone button on the home screen). Once a day the app checks the App Store lookup API for a newer version and, if one exists, shows a notice with a button that opens the App Store page. This is the only network request besides Game Center.
```
