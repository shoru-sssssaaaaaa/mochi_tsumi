## Appのプライバシー（「栄養ラベル」）

「データの収集」の質問に **「いいえ、このAppからデータを収集しません」** と答えて公開します。

理由：通信を一切しない、広告もない、分析ツールも入れていない。進みぐあい（どのステージまで進んだか・音のオン/オフ）は iPhone の中（UserDefaults）にだけ保存され、外に送られません。

## 年齢制限

質問はすべて「なし」「いいえ」で答えます（暴力・ギャンブル・ユーザー同士のやりとり・Webブラウズ・広告・App内課金、いずれもなし）。結果は一番低い区分（4+）になるはずです。

## 輸出コンプライアンス（暗号化）

Info.plist に「暗号化を使っていない（ITSAppUsesNonExemptEncryption = NO）」と書いてあるので、ビルドごとに聞かれることはありません。

## 審査メモ（App Reviewへのメッセージ欄に英語で貼る）

「App Review に関する情報」→「メモ」に貼っておくと、審査の人に「中身がきちんとしたゲームであること」が伝わりやすくなります。ログインは不要なので、サインイン情報の欄はオフにします。

```
Mochitto Tsumitsumi is a fully offline physics puzzle game. No account, no network access, no ads, no in-app purchases.

How to play: tap the screen to drop a rice cake (mochi). Stack them so the top stays above the gold line for about one second to clear the stage. Each stage gives a fixed set of mochi. The five mochi types have different physics (weight, softness, stickiness, friction), so the stacking order matters: for example, heavy "anko" is a stable base, and powdered "kinako" makes anything on top slide off.

The game engine is bundled inside the app and runs locally. It uses native iOS features: haptic feedback on landing, clear and fail; progress saved on the device with UserDefaults; an ambient audio session so it respects the silent switch and the user's music.

"Free play" mode (from the ? Rules screen) lets you drag and stretch the mochi without goals.
```
